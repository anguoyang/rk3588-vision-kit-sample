用血泪换来的规矩

警告

工具链与运行时必须同行。 用 toolkit 2.3.2 转换的产物，只在 runtime 2.3.2 上验证过。2.3.x 工具链配 2.0/2.1 运行时（或反过来） 会报加载错误，或者悄无声息地掉精度。本套件把这一对锁死。

备注

工具链只有 x86_64 版。 转换在 x86_64 主机上做，板卡只负责运行 产物。包内管线脚本按这个分工写。

备注

运行时不随包分发。 librknnrt 是 Rockchip 专有软件。套件提供 旁载安装说明与版本校验，不提供二进制。
