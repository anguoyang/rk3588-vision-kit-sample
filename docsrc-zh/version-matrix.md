# 版本矩阵

本套件的每个产物和每个数字都绑定下面这套组合。这是整份文档里最有
价值的一页：RKNN 部署的故障，绝大多数是版本不匹配。

## 已测配置（参考）

| 组件 | 版本 | 备注 |
|---|---|---|
| SoC | Rockchip RK3588 | NPU 6 TOPS，驱动中显示为 `RKNPU` |
| 板卡系统 | Ubuntu 22.04.5 LTS | |
| 内核 | 6.1.118 | |
| NPU 驱动 | 0.9.8 | `dmesg \| grep -i rknpu` |
| 运行时（`librknnrt`） | 2.3.2 | 构建 `429f97ae6b@2025-04-09` |
| 转换工具链 | rknn-toolkit2 2.3.2 | 仅 x86_64 主机；不在板上运行 |
| 主机 Python | 3.10–3.12 | 转换环境 |
| 板卡 Python | 3.10 | 与运行时 2.3.2 配套的 RKNNLite2 |

## 用血泪换来的规矩

```{warning}
**工具链与运行时必须同行。** 用 toolkit 2.3.2 转换的产物，只在
runtime 2.3.2 上验证过。2.3.x 工具链配 2.0/2.1 运行时（或反过来）
会报加载错误，或者悄无声息地掉精度。本套件把这一对锁死。
```

```{note}
**工具链只有 x86_64 版。** 转换在 x86_64 主机上做，板卡只负责运行
产物。包内管线脚本按这个分工写。
```

```{note}
**运行时不随包分发。** `librknnrt` 是 Rockchip 专有软件。套件提供
旁载安装说明与版本校验，不提供二进制。
```
