# バージョン対応表

本キットの成果物と数値はすべて、以下の組み合わせに紐付いています。
このドキュメントで最も価値のあるページです。RKNN デプロイの障害は、
圧倒的にバージョン不一致が原因だからです。

## テスト済み構成（リファレンス）

| コンポーネント | バージョン | 備考 |
|---|---|---|
| SoC | Rockchip RK3588 | NPU 6 TOPS、ドライバ上は `RKNPU` |
| ボード OS | Ubuntu 22.04.5 LTS | |
| カーネル | 6.1.118 | |
| NPU ドライバ | 0.9.8 | `dmesg \| grep -i rknpu` |
| ランタイム（`librknnrt`） | 2.3.2 | ビルド `429f97ae6b@2025-04-09` |
| 変換ツールキット | rknn-toolkit2 2.3.2 | x86_64 ホスト専用。ボード上では動きません |
| ホスト Python | 3.10–3.12 | 変換環境 |
| ボード Python | 3.10 | ランタイム 2.3.2 対応の RKNNLite2 |

## 痛い目を見て得たルール

```{warning}
**ツールキットとランタイムは必ずセットで。** toolkit 2.3.2 で変換した
成果物は runtime 2.3.2 でのみ検証済みです。2.3.x ツールキットと
2.0/2.1 ランタイムの混在（またはその逆）は、ロードエラーか、静かな
精度低下を招きます。本キットはこのペアを固定しています。
```

```{note}
**ツールキットは x86_64 専用。** 変換は x86_64 ホストで行い、ボードは
成果物を実行するだけです。パッケージ内のパイプラインスクリプトは
この分担を前提にしています。
```

```{note}
**ランタイムは再配布しません。** `librknnrt` は Rockchip の
プロプライエタリソフトウェアです。本キットにはバイナリではなく、
サイドロード手順とバージョンチェックが入っています。
```
